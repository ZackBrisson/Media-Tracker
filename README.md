# Media Tracker

This Media Tracker program is a web application to track, store, add, and recommend different forms of Media. It is starting with books and can add books, search their library, filter by reading status, update a book's status, delete books, and save their library in the browser using localStorage.

## Current Features

- Add books with title, author, pages, genre, sub genre, book cover, series, and reading status
- Display books as individual cards
- Search books by title or author
- Filter books by reading status
- Update a book's reading status
- Delete books from the list
- Save books using localStorage
- Show an empty-state message when no books are found
- Basic Books page layout with search, add book, book list, and recommendations sections
